\section*{Return Times, Kakutani Skyscrapers, and Rokhlin Towers}
% BLOG-CONTENT-BEGIN
In the last post we saw mixing systems. There is a deep question concerning
mixing systems, which we addressed last time, called the Rokhlin problem. In
this final (almost) post we shall see beautiful work of Rokhlin and Kakutani:
Rokhlin towers and Kakutani skyscrapers.

\subsection{Induced Transformations}
Let us work with the system $(X,\mathcal B,\mu,T)$, where $T$ is invertible.
The very first result that we proved---a result that revealed the first
emergence of a pattern---was Poincar\'e's recurrence theorem. It tells you
that, given a set $A$, almost all points of $A$ under $T$ keep hitting $A$ ad
infinitum. Now let us quantify the implication of that theorem by asking:
\begin{quote}
What is the expected return time to $A$? Assume $\mu(A)>0$.
\end{quote}
We shall address that question by looking at the first return time to $A$.
This shall suffice, for the second return time is the first for the iterated
image of the starting point, and so on.

Define
\[
 r_A(x):=\inf_{n\geq1}\{n\mid T^n(x)\in A\}.
\]

% Source page 2
This quantity $r_A$ gives us a natural way of defining a transformation on
$A$.
\setcounter{definition}{8}\begin{definition}[Induced transformation]
Define $T_A\colon A\to A$ by $T_A(x):=T^{r_A(x)}(x)$. This is defined almost everywhere on $A$, and is called the transformation \emph{induced by $T$ on $A$}, or the \emph{induced transformation on $A$}.
\end{definition}

\begin{itemize}
\item $r_A\colon A\to\mathbb N$ is defined almost everywhere and is measurable, because we have
\[
\begin{aligned}
 \text{``first return'':}\quad \{x\in A\mid r_A(x)=1\}&=A_1=A\cap T^{-1}(A),\\
 \text{``second return'':}\quad \{x\in A\mid r_A(x)=2\}&=A_2=(A\cap T^{-2}(A))\setminus A_1,\\
 &\ \vdots\\
 \text{``$n$th return'':}\quad \{x\in A\mid r_A(x)=n\}&=A_n=(A\cap T^{-n}(A))\setminus\bigcup_{i<n}A_i.
\end{aligned}
\]
As $A_n$ is measurable for every $n\geq1$, $r_A$ is measurable, for the sets $\{n\}$ generate the $\sigma$-algebra on $\mathbb N$.
% Source writes X -> N although r_A may be infinite outside the returning set; retained.

\item $T_A\colon A\to A$ is also measurable. Since $T$ is invertible, for $B\in\mathcal B$ with $B\subseteq A$, notice that
\[
 T_A^{-1}(B)=\bigcup_{n\geq1}\bigl(A_n\cap T^{-n}(B)\bigr)
 \quad\text{almost everywhere},
\]
as $T^{-1}$ is defined almost everywhere.
\end{itemize}

% Source page 3
\begin{itemize}
\item $\bigl(A,\mathcal B|_A,\mu_A=\frac1{\mu(A)}(\mu|_A),T_A\bigr)$ is a measure-preserving system.
\item As is to be naturally expected, if $T$ is ergodic, then so is $T_A$.
Firstly, notice that $A=\bigsqcup_{n\geq1}A_n$. Thus, if
$B\in\mathcal B|_A$, then $B=\bigsqcup_{n\geq1}(B\cap A_n)$, so
\[
 \mu_A(B)=\frac1{\mu(A)}\sum_{n\geq1}\mu(B\cap A_n),
 \qquad
 T_A(B)=\bigsqcup_{n\geq1}T_A(B\cap A_n)
       =\bigsqcup_{n\geq1}T^n(B\cap A_n).
\]
Hence
\[
\begin{aligned}
 \mu_A(T_A(B))
 &=\frac1{\mu(A)}\sum_{n\geq1}\mu\bigl(T^n(B\cap A_n)\bigr)\\
 &=\frac1{\mu(A)}\sum_{n\geq1}\mu(B\cap A_n)
   &&\text{($T$ is $\mu$-invariant)}\\
 &=\mu_A(B).
\end{aligned}
\]
If $T_A$ is not ergodic, there exists $B$ with $T_A^{-1}(B)=B$ and $0<\mu(B)<\mu(A)$, i.e. $0<\mu_A(B)<1$. Then
\[
 \bigcup_{n\geq1}\ \bigcup_{j=0}^{n-1}T^j(B\cap A_n)
\]
is $T$-invariant and has nonzero measure. The corresponding saturation of $A\setminus B$ also has nonzero measure, so the displayed invariant set does not have full measure. This contradicts ergodicity of $T$.
\end{itemize}

Having addressed the nature of the induced transformation, let us introduce
Kakutani skyscrapers and see how a simple construction can help us get two
marvellous results, one of them addressing the question raised at the
beginning of the post.

% Source page 4
\subsection{Kakutani Skyscrapers}
\begin{figure}[htbp]
 \centering
 \includegraphics[width=.92\textwidth]{lecture5-fig-01.pdf}
 \FigureTag{L5.1}{fig:lecture5-fig-01}
\end{figure}

\paragraph{Description.}
The ground floor represents $A$ as a disjoint union of sets
$\{A_k\}_{k\geq1}$. By definition, points in $A_2$ travel to some set before
returning to $A$. The first floor consists of the sets $A_2$ onwards lifted to
a set beyond $A$; the second floor is obtained similarly, and the $n$th floor
inductively. $T_A$ takes points in $A_3$, for instance, on a ride to all the
floors above it and lands on $A$.

\begin{remark}
Poincar\'e recurrence is basically saying that the ground floor has
$\{A_k\}_{k\geq1}$ almost everywhere, and hence the tower above it. Ergodicity
of $T$ tells you that almost every point of $X$ belongs to some floor of the
skyscraper, as $\mu(A)>0$.
\end{remark}

% Source page 5
\setcounter{theorem}{16}\begin{theorem}[Expected Return Time, due to Kac]\label{thm:l5-kac}
Let $(X,\mathcal B,\mu,T)$ be an invertible ergodic system. If $\mu(A)>0$, then
\[
 \int_A r_A\,d\mu=1.
\]
In other words, the expected return time is
\[
 \frac1{\mu(A)}\int_A r_A\,d\mu=\frac1{\mu(A)}.
\]
\end{theorem}
\Needspace{5\baselineskip}
\begin{proof}
Since $T$ is invertible, ergodicity of $T$ implies ergodicity of $T^{-1}$. As
we know, $\mu\bigl(\bigcup_{n\geq1}T^n(A)\bigr)=1$, so the skyscraper contains
almost all of $X$. Thus, summing up tower-wise,
\[
\begin{aligned}
 1=\mu(X)
 &=\sum_{n\geq1}\mu\bigl(A_n\sqcup T(A_n)\sqcup\cdots\sqcup T^{n-1}(A_n)\bigr)\\
 &=\sum_{n\geq1}n\mu(A_n)=\int_A r_A\,d\mu,
\end{aligned}
\]
as $\sum_{k=1}^n k\chi_{A_k}\nearrow r_A$.
\end{proof}
Therefore, the bigger the set, the sooner the points will return. In
particular, if $\mu(A)>\frac12$, then the expected return time is less than
$2$.

\setcounter{theorem}{17}\begin{theorem}[Rokhlin's Tower Decomposition]\label{thm:l5-rokhlin}
In the setting of Theorem~\ref{thm:l5-kac}, suppose that $\mu(\{x\})=0$ for all $x\in X$, i.e. $\mu$ is nonatomic. Then for every $n\geq1$ and $\varepsilon>0$, there exists $B\in\mathcal B$ such that
\begin{itemize}
 \item $B,T(B),\ldots,T^{n-1}(B)$ are disjoint;
 \item $\displaystyle\mu\left(\bigsqcup_{k=0}^{n-1}T^k(B)\right)>1-\varepsilon$.
\end{itemize}
\end{theorem}

% Source page 6
\begin{proof}
A nonatomic measure is a measure which has no ``atoms''. In mathematical
terms, given $E\in\mathcal B$,
there exists $F\in\mathcal B$, $F\subset E$, such that $0<\mu(F)<\mu(E)$. Then $\mu(F)$ or
$\mu(E\setminus F)$ is less than $\mu(E)/2$. Iterating this construction, one
can construct
measurable sets satisfying
\[
 \mu(\widetilde F)<\frac{\mu(E)}{2^n}<\frac1{2^n}.
\]
Now, given $n$ and $\varepsilon$, select $A\in\mathcal B$ such that $0<\mu(A)<\varepsilon/n$. The skyscraper yields the decomposition of $X$ into towers
\[
 A_k\sqcup T(A_k)\sqcup\cdots\sqcup T^{k-1}(A_k).
\]
Set
\[
 B=\bigsqcup_{k\geq n}\ \bigsqcup_{j=0}^{\lfloor k/n\rfloor-1}T^{jn}(A_k).
\]
Then $B,T(B),T^2(B),\ldots,T^{n-1}(B)$ are disjoint; each belongs to a particular residue class modulo $n$. The set $\bigcup_{k=0}^{n-1}T^k(B)$ is all of $X$ except those sets in the skyscraper comprising no more than $n$ floors in each tower. Therefore
\[
 \mu\left(\left(\bigsqcup_{k=0}^{n-1}T^k(B)\right)^c\right)
 \leq n\sum_{k=1}^{\infty}\mu(A_k)
 \leq n\mu(A)<\varepsilon,
\]
which implies $\mu\bigl(\bigsqcup_{k=0}^{n-1}T^k(B)\bigr)>1-\varepsilon$.
\end{proof}

\Needspace{11cm}
Pictorially speaking, this is what happened. Let us represent towers by
numbers.

 \centering
 \includegraphics[width=.66\textwidth]{lecture5-fig-02.pdf}
 \FigureTag{L5.2}{fig:lecture5-fig-02}
\end{figure}
\[
\renewcommand{\arraystretch}{1.25}
\begin{array}{r@{\,=\,}ccccccc}
 B      &1&1&1&1&\begin{gathered}[b]5\\1\end{gathered}&\begin{gathered}[b]5\\1\end{gathered}&\cdots\\
 T(B)   &2&2&2&2&\begin{gathered}[b]6\\2\end{gathered}&\begin{gathered}[b]6\\2\end{gathered}&\cdots\\
 T^2(B) &3&3&3&3&\begin{gathered}[b]7\\3\end{gathered}&\begin{gathered}[b]7\\3\end{gathered}&\cdots\\
 T^3(B) &4&4&4&4&\begin{gathered}[b]8\\4\end{gathered}&\begin{gathered}[b]8\\4\end{gathered}&\cdots
\end{array}
\]
Since we are stopping at $\lfloor k/n\rfloor-1$, all towers between $A_4$ and
$A_8$ will have no means of reaching floors beyond $4$. Similarly, towers
between $A_8$ and $A_{12}$ will have no means of reaching beyond the eighth
floor, and so on. Each tower will have some residual floors, unattended by
iterates of $B$, and there can be at most $4$ in our case.

This decomposition is usually called a \emph{Rokhlin tower of height $n$ with base $B$ and residual set of measure less than $\varepsilon$}.
