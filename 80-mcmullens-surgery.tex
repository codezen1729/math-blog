In \BlogPost{third-surgery}{Part I}, the Gluing Lemma gave us the mechanism for cutting and pasting along ideal boundaries. One of the means of carrying out this successive surgery would be by pasting certain rigid models, defined as follows:

    \subsection*{Definition 6.14}{(Rigid Models)}: We give here three rigid models for proper self maps of the unit disk as:
    \begin{enumerate}
        \item The elliptic model $z\rightarrow e^{2\pi i\theta}z$, for $\theta \in \mathbb{R}\backslash \mathbb{Q}$,
        \item The hyperbolic model $z\rightarrow z^d$ for some $d>1$,
        \item The parabolic model $z \rightarrow P_d(z)$ for $d>1$, where
        $$P_d(z):= \frac{z^d + a}{1+az^d}   \text{for}   a = \frac{d-1}{d+1}$$
    \end{enumerate}

    Let $M_a(z)=(z+a)/(1+az)$. The composition in the notes is correctly read as $P_d=M_a\circ(z\mapsto z^d)$. If $|z|=1$ and $z=x+iy$, then
    \[
    \begin{aligned}
    |z+a|^2&=|1+az|^2,\\
    (x+a)^2+y^2&=(1+ax)^2+a^2y^2,\\
    (x^2+y^2)(1-a^2)+a^2&=1.
    \end{aligned}
    \]
    The last equality follows from $x^2+y^2=1$, and proves $|P_d(z)|=1$ on $\mathbb S^1$.

    Thus $P_d(\mathbb{S}^1)=\mathbb{S}^1$, and $P_d$ is orientation-preserving. Hence $P_d(\mathbb{D})=\mathbb{D}$ and $P_d(\widehat{\mathbb{C}}\setminus\overline{\mathbb{D}})=\widehat{\mathbb{C}}\setminus\overline{\mathbb{D}}$. By Montel's theorem, $P_d$ is normal on $\mathbb{D}$ and $\widehat{\mathbb{C}}\setminus\overline{\mathbb{D}}$. Since $\mathbb{S}^1$ is their common boundary, $J(P_d)=\mathbb{S}^1$.



    Let $B(z) = e^{2\pi i\theta}z$, and let $\phi$ be an orientation preserving circle homeomorphism such that $\phi\circ B = B\circ\phi$. A lift initially satisfies $F(z+\theta)=F(z)+\theta+k$ for some integer $k$, while $F(z+1)=F(z)+1$. Since $F(z)-z$ is bounded and iterating the first identity would produce the term $nk$, we must have $k=0$. Thus $F(z+\theta) = F(z) + \theta$, and $F(z)-z$ is $1$-periodic. This implies $F(m\theta + n) = F(0) + m\theta+n$; now as $m\theta + n$ is dense in $\mathbb{R}$, we get that $F(z) = z+\alpha$ $\implies$ $\phi$ is a rotation.\\

    Let $B(z) = z^d$, and let $h$ be a topological orientation preserving map satisfying $h(z^d) = h(z)^d$ for all $z \in \mathbb{S}^1$. Set $\tilde{h} = h/h(1)$. Since $h(1)=h(1)^d$, $h(1)$ is a $(d-1)$th root of unity and $\tilde{h}$ still commutes with $z^d$. If $\zeta^{d^k}=1$, then commutation gives $\tilde{h}(\zeta)^{d^k}=1$. Thus $\tilde{h}$ permutes the $d^k$th roots of unity; as it preserves orientation and fixes $1$, it fixes each of them. Their union is dense in $\mathbb{S}^1$, so $\tilde{h} = \text{Id}$ on $\mathbb{S}^1$. Therefore, $h(z) = h(1)z$, making it a rotation map.\\
    Further note that $\phi_1(z) = z$ and $\phi_2(z) = \frac{z+a}{1+az}$ provide an equivalence between $z \rightarrow z^d$ and $z \rightarrow P_d(z)$, since $P_d=\phi_2\circ(z\mapsto z^d)$. They are not even topologically conjugate on $\mathbb{S}^1$: $P_d$ has a parabolic fixed point, with nearby points converging to it from one side, whereas every fixed point of $z\mapsto z^d$ is repelling.\\

    Indeed,
    \[
    P_d'(z)=\frac{d(1-a^2)z^{d-1}}{(1+az^d)^2},
    \]
    so the two critical points are $0$ and $\infty$, each of multiplicity $d-1$, and $P_d(z)-z$ has a zero of order $3$ at $z=1$.

    The accompanying notebook argument calls the welded fixed point both multiplicity $3$ and multiplicity $2$, so that cusp argument by itself is not a valid proof of rigidity. The needed centralizer statement follows directly: if an orientation-preserving circle homeomorphism $h$ commutes with $P_d$, it fixes the unique parabolic fixed point $1$. For every $n$, it preserves the finite cyclically ordered set $\operatorname{Fix}(P_d^{\circ n})$; an order-preserving permutation of this set that fixes $1$ is the identity. The repelling periodic points are dense in $J(P_d)=\mathbb S^1$, and hence $h=\operatorname{Id}$.

    These three observations in conjunction establish some sense of rigidity as far as these objects' conjugacy classes are concerned. Now let us state the main theorem in which the core of McMullen's surgery resides.

    \subsection*{Theorem 6.15}{(Main Theorem)}: Let $f$ be a rational map and $C \subset J(f)$ a component different from a single point such that $f(C)=C$. Then there exists a rational map $g$ and a quasiconformal homeomorphism $\phi: \hat{\mathbb{C}} \rightarrow \hat{\mathbb{C}}$ such that $\phi$ stable conjugates $f\big|_C$ to $g\big|_{J(g)}$. Moreover, $g$ has the following properties. The Julia set $J(g)$ is connected and the periodic Fatou components of $g$ are Siegel discs, basins of superattraction or parabolic basins. On each periodic Fatou component, the first return map is conjugate to one of the three rigid models. Moreover, if $c$ is a critical point in a strictly preperiodic Fatou component, and $n$ is the smallest number for which $g^{\circ n}(c)$ is in a periodic component $U$, then:
    \begin{enumerate}
        \item if $U$ is a Siegel disc, $g^{\circ n}(c)$ is the indifferent point in $U$; i.e. the center of the Siegel disc;
        \item if $U$ is a basin of superattraction, $g^{\circ n}(c)$ is the superattracting periodic point;
        \item if $U$ is a parabolic basin, $g^{\circ (n +k)}(c)$ is a critical point, where $k$ is the smallest number for which $g^{\circ k}(U)$ contains a critical point.
    \end{enumerate}


    To prove the Main Theorem we need to understand what kind of maps $f$ induces on the different components of the ideal boundary of $C$. We shall summarize that first in the following two propositions.

    \subsection*{Proposition 6.16}{(Global Dynamics of $\hat{f}$ on $I(C)$)}:
    \begin{enumerate}
        \item All but finitely many components of $\hat{\mathbb{C}}\backslash C$ map to their images by a conformal isomorphism.
        \item Every component of $I(C)$ is preperiodic and there are only finitely many periodic ones.
        \item For any component $I(U)$ of $I(C)$, there exist quasisymmetric maps $\hat{\phi}_1$ and $\hat{\phi}_2$ mapping $I(U)$ and $\hat{f}(I(U))$ respectively to $\mathbb{S}^1$ that provide an equivalence between $\hat{f}$ and $z\rightarrow z^d$ for some $d\geq 1$. If $I(U)$ is fixed, $\hat{f}$ and $z\rightarrow z^d$ may not be quasisymmetrically conjugate.
    \end{enumerate}
    (Note: The equivalence between $\hat{f}$  and $z\rightarrow z^d$ for some $d\geq 1$ can be changed to an equivalence between $\hat{f}$  and any Blaschke product of degree $d$ on $\mathbb{S}^1$. There is also a lot of freedom in the choices of the quasisymmetric maps $\hat{\phi}_1$ and $\hat{\phi}_2$ providing the equivalence, in that, for an arbitrary choice of one, one can obtain the other).


    \subsection*{Proposition 6.17}{(Dynamics of $\hat{f}$ on Periodic Components of $I(C)$)}: On each periodic component of $I(C)$, the first return map is quasisymmetrically conjugate to one of the three rigid models.



    Proof of Proposition $6.16$. There are only finitely many components $V_1, V_2,\ldots, V_k$ of $\hat{\mathbb{C}}\backslash C$ which intersect $f^{-1}(C)$ or contain a critical point. Set $\mathcal{V} = \{V_j\}_{1\leq j\leq k}$.\\
    Proof of (1). If $U$ is a component of $\hat{\mathbb{C}}\backslash C$ not in $\mathcal{V}$, then $f$ maps $U$ onto another component of $\hat{\mathbb{C}}\backslash C$ as a covering. Since $U$ is a disk, $f\big|_U$ is a conformal isomorphism onto its image. \\
    Proof of (2). Let $U$ be a component of $\hat{\mathbb{C}}\backslash C$ not in $\mathcal{V}$. Suppose $f^{\circ n}(U)$ is not in $\mathcal{V}$ for any $n\geq 0$. Then, $f^{\circ n}$ is normal on $U$ and therefore $f^{\circ n}(U)$ must eventually cycle, otherwise $U$ would be a wandering domain which \BlogPost{first-surgery}{Sullivan's No Wandering Theorem} rules out for a rational map. Hence, $U$ is eventually mapped onto a Fatou component whose first return map is a conformal isomorphism, and therefore a Siegel disk. It follows that $I(U)$ is preperiodic. If, on the other hand, $f^{\circ n}(U)$ is eventually mapped onto one of the components in $\mathcal{V}$ then $I(U)$ must also be preperiodic. Indeed, if some iterate is mapped onto $I(W)$ for $W \notin \mathcal{V}$, we can repeat the argument from before: the component $W$ is eventually mapped onto a Siegel disk or onto one of the components in $\mathcal{V}$. Since there are only finitely many components in $\mathcal{V}$, the ideal boundary $I(U)$ will eventually cycle. There is a finite number of periodic components in $I(C)$, since there are at most finitely many cycles of Siegel disks and finitely many components in $\mathcal{V}$ (as the number of cycles of indifferent points is finite).\\

Uniformize these two annuli separately. In these coordinates the covering is equivalent to $z\rightarrow z^d$, and the induced circle coordinates differ real analytically from those obtained by uniformizing the two disks. We therefore get quasisymmetric maps $\psi_1$ and $\psi_2$ providing an equivalence between $\hat{f}:I(U)\rightarrow \hat{f}(I(U))$ and $z\rightarrow z^d$ for some $d\geq 1$.\\

    \[
    (\text{anything})\circ\phi_1\circ R_U
    \neq(\text{lift})\circ\phi_2\circ R_V.

    When $U$ is fixed, independently choosing the two annular coordinates gives only a two-sided equivalence and need not give a conjugacy. This is precisely the periodic obstruction addressed by Proposition $6.17$.

    Now let us devote some time to prove Proposition $6.17$ through a sequence of lemmas which shall study each type of periodic component of $I(C)$ separately. Let $U$ be a component of $\hat{\mathbb{C}}\backslash C$ for which $I(U)$ is periodic under $\hat{f}$. Replacing $f$ by a suitable iterate, we may assume that $I(U)$ is fixed. Recall from the discussion above that there is a collar annulus $U' \subset U$, whose boundary component facing $C$ represents $I(U)$, such that $f$ is a covering onto its image.

    \subsection*{Lemma 6.18}: Suppose $\hat{f}(I(U)) = I(U)$. If $U'$ can be chosen to be a proper subset of $f(U')$ then $\hat{f}$ is quasisymmetrically conjugate to $z\rightarrow z^d$ for some $d>1$.


    \textit{Proof.}: In the proof of the above lemma we shall use the following theorem. A complete treatment of the theorem and expanding maps can be found in \cite{shub1985expanding}, \cite{hubbard1982iteration} and \cite{de2012one}.
    \subsection*{Theorem 6.19}: Any expanding\footnote{A real-analytic endomorphism on $\mathbb{S}^1$ is said to be expanding if there is a smooth metric $\rho(\theta)\text{d}\theta$ with respect to which the derivative of the map is everywhere $>1$.} $C^{1+\alpha}$ orientation preserving endomorphism of $\mathbb{S}^1$ is quasisymmetrically conjugate to $z\rightarrow z^d$ for some $d>1$.


    Uniformize $U$. By the Schwarz Reflection Principle, the map in these coordinates extends to a holomorphic covering $F:A\rightarrow B$, where $A$ and $B$ are annuli containing $\mathbb{S}^1$ and $A$ is a proper subset of $B$. The covering is a local isometry between the Poincar\'e metrics of $A$ and $B$, while the Poincar\'e metric of $A$ is strictly larger than the one inherited from $B$. It follows that $F$ is expanding on $\mathbb{S}^1$ relative to the Poincar\'e metric of $B$. By Theorem $6.19$, the result follows.

    For the symmetric annulus $\mathbb A_{R,1/R}=\{R<|z|<1/R\}$, $0<R<1$, the source calculation uses the Poincar\'e density
    \[
    \lambda_R(z)=\frac{\pi}{2\log(1/R)}
    \frac{1}{|z|\cos\!\left(\dfrac{\pi\log|z|}{2\log(1/R)}\right)}.
    \]
    The local-isometry identity is, with the domain and target densities distinguished,
    \[
    \lambda_B(F(z))|F'(z)|=\lambda_A(z).
    \]
    Since $A\subsetneq B$, monotonicity gives $\lambda_A>\lambda_B$ on $A$, which is the expansion used above on $\mathbb S^1$.


    \subsection*{Lemma 6.20}: Suppose $\hat{f}: I(U) \rightarrow I(U)$. Either $\partial U \subset \partial V$ for some Fatou component $V \subset U$ or $\hat{f}:I(U)\rightarrow I(U)$ is quasisymmetrically conjugate to $z\rightarrow z^d$ for some $d>1$.


    \textit{Proof.}: To prove this lemma we shall need the following theorem due to Zoretti which can be found in \cite{whyburn1948analytic}.
    \subsection*{Theorem 6.21}{(Zoretti's Theorem)}: Let $C$ be a component of a compact set $J \subset \mathbb{R}^2$. For all $\epsilon >0$ there exists a simple closed curve $\gamma_{\epsilon}$ which encloses $C$ and is such that $\gamma_{\epsilon}\cap J = \emptyset$ and $\text{dist}(C, x) < \epsilon$ for all $x\in \gamma_{\epsilon}$.

    Suppose first that $\partial U$ is not contained in the boundary of any Fatou component in $U$. In $\overline{U}$, $\partial U$ is a component of $\overline{U}\cap\overline{J(f)}$ $\implies$ one can apply Zoretti's Theorem to get simple closed curves $\gamma_n$ in the Fatou set, each lying in an $\epsilon_n$-neighbourhood of $\partial U$, where $\epsilon_n\rightarrow 0$. These curves lie in infinitely many distinct Fatou components. Since there are only finitely many periodic Fatou components, choose $n$ large enough that $\gamma_n$ lies in an aperiodic component and the annulus $V'$ bounded by $\gamma_n$ and $\partial U$ contains no critical values.\\
    There is a unique component $U'$ of $f^{-1}(V')$ in $U$, bounded by $\partial U$ and a preimage of $\gamma_n$. Since $\gamma_n$ lies in an aperiodic component, it is disjoint from its preimage $\implies$ either $U'\subset V'$ or $V'\subset U'$; equality cannot hold. But $f:U'\rightarrow V'$ is a proper covering and $\text{mod}(U')\leq\text{mod}(V')$. This gives us that $U'$ is a proper subset of $V' = f(U')$, and the lemma follows from the previous lemma.

    Now we are left to handle the cases $\partial U \subset \partial V$, where $V \subset U$ is a Fatou component. By the classification theorem of periodic Fatou components for rational maps, $V$ can only be a Siegel disk, a Herman ring, a basin of (super)attraction, or a parabolic basin. We deal with these cases separately in a bunch of lemmas to follow.

    \subsection*{Lemma 6.22}: If $V$ is fixed Siegel disk or a fixed Herman ring of rotation number $\theta \in \mathbb{R}\backslash\mathbb{Q}$, then $\hat{f}$ is real analytically conjugate to the rigid rotation $R_{\theta} = e^{2\pi i \theta}z$


    \textit{Proof.}: If $V$ is a Siegel disk then $U=V$ and a Riemann mapping $R_U$, which maps the indifferent fixed point to $0$, conjugates $f$ to the rigid rotation on $\mathbb{D}$. Hence $\hat{f}$ on $\mathbb{S}^1$ is actually equal to $R_{\theta}$. If $V$ is a Herman ring, then there is a conformal map $\phi:V \rightarrow \mathbb{A}_r$ conjugating $f$ to $R_{\theta}$. In this case, arguing as we did in Proposition $6.16$, we obtain that $\hat{f}$ on $I(U)$ is real analytically conjugate to $R_{\theta}$.

    \subsection*{Lemma 6.23}: If $V$ is an immediate basin of (super)attraction, or a parabolic basin whose parabolic fixed point is not on $\partial U$, then $\hat{f}$ is quasisymmetrically conjugate to $z\rightarrow z^d$ for some $d>1$.


    \textit{Proof.}: Let $W \subset V$ be a Jordan domain, for which $f(W)$ is a proper subset of $W$ and $\overline{W}$ does not intersect $\partial U$. In the (super)attraction case $W$ may be chosen as disk surrounding the (super)attracting fixed point and mapping inside itself. In the parabolic case $W$ may be chosen as an attracting petal in the parabolic basin so that $\overline{W}$ intersects $\partial V$ at the parabolic fixed point.\\
    Let $W_n$ be the component of $f^{\circ (-n)}(W)$ containing $W$, then
    $$\overline{W} \subset \overline{W_1} \subset \overline{W_2} \subset \ldots
    $$

    and $\bigcup_{n}{W_n} = V$. In the parabolic case, $\partial U$ cannot contain any point in the grand orbit of the parabolic point since $f(\partial U) = \partial U$, so $W_n \cap \partial U = \emptyset$ for all $n>0$. Observe that, if $V$ is not simply connected, $W_n$ will become multiply connected after a certain $n_0$, since the union of all the $W_n$'s must account for all of $V$.\\
    For every $n$, there is a component of $\partial W_n$ which together with $\partial U$ bounds an annulus $A_n$ disjoint from $W_n$. In general, $A_n$ may contain infinitely many different components of the Julia set. Each annulus lies in an $\epsilon_n$-neighbourhood of $\partial U$, where $\epsilon_n \rightarrow 0$ as $n\rightarrow \infty$. Otherwise there is a continuum in $\partial V$ which lies in $U$ and meets $\partial U$, contradicting the fact that $C$ is a component of the Julia set.\\
    Choose $n$ sufficiently large so that $A_n$ contains no critical values. The component of $\partial W_n$ which, together with $\partial U$, bounds $A_n$ is essentially the component that hits rays from $\partial U$ to $W_n$ first. This fact, along with $f(W_{n+1}) = W_n$, ensures that $A_{n+1}$ is a component of $f^{-1}(A_n)$ and a proper subset of $A_n$. Lemma $6.18$ now applies.

    \subsection*{Lemma 6.24}: If $V$ belongs to a parabolic basin, with a parabolic fixed point on $\partial U$, then $\hat{f}$ on $I(U)$ is quasisymmetrically conjugate to $P_d(z)$ for some $d>1$.


    \textit{Proof.}: Let $R_U:U\rightarrow \mathbb{D}$ be a Riemann map, normalized so that the parabolic fixed prime end corresponds to $z=1$. Then the coordinate form of $f$, together with $V$, carries over to $\mathbb{D}$, where we continue to denote them by $f$ and $V$. Observe that this coordinate form of $f$ is defined only on a subset of the disk, and that its domain contains $V$ and a one-sided neighbourhood of $\mathbb{S}^1$. By the Schwarz Reflection Principle, it can be extended to a holomorphic map on a neighbourhood of $\mathbb{S}^1$ having a parabolic fixed point at $z=1$. The restriction to the unit circle is precisely $\hat{f}$. We construct by hand a quasisymmetric conjugacy between $\hat{f}$ and $P_d$, where $d$ is the degree of $\hat{f}$ on $\mathbb{S}^1$.\\

As before, let $W_n$ denote the component of $f^{\circ (-n)}(W)$ containing $W$. For $n$ sufficiently large, there is a unique component $\gamma_n$ of $\partial W_n$, lying between $\partial U$ and $W_n$, and touching $\mathbb{S}^1$ at the $n$-th preimages of $z=1$. This curve $\gamma_n$ is contained in the annulus where $f$ is a covering.\\
    The curves $\gamma_n$ and $\gamma_{n+1}$ bound a pinched annulus $A_n$ with several components. This pinched annulus is, in a sense, a fundamental domain, since all forward orbits of points in between $\mathbb{S}^1$ and $\gamma_{n+1}$ must pass once and only once through $A_n \cup \gamma_n$.\\

    The final notebook page proposes the following rigour step: first extend $\Psi_n$ smoothly to the rest of the annulus bounded by $\mathbb S^1$ and $\gamma_n$, obtaining $\widehat\Psi_n$, and then claim $\widehat\Psi_n\to\Psi$ because $H^1(\widetilde U)$ is Cauchy complete.     Let us apply Propositions $6.16$ and $6.17$ in a sequence of surgeries to establish the main theorem.

    Proof of Main Theorem. Suppose $I(U)$ is periodic of period $p\geq 1$. Following Proposition $6.17$, let $\hat{\phi}:I(U)\rightarrow \mathbb{S}^1$ be a quasisymmetric map so that $\hat{\phi}\circ \hat{f}^p\circ \hat{\phi}^{-1}$ equals exactly one of the rigid models, say $B_U$. Choose a Riemann mapping $R_U:U \rightarrow \mathbb{D}$. The ideal boundary values of $R_U$ identify $I(U)$ with $\mathbb{S}^1$, so $\hat{\phi}$ determines a quasisymmetric self-map of the circle. Extend this self-map quasiconformally over $\mathbb{D}$ and compose it with $R_U$ to obtain $\phi:U\rightarrow\mathbb{D}$. It follows that $f^{\circ p}$ and $B_U$ are compatible on the ideal boundary via $\phi$. If $p=1$ this periodic component is dealt with: replacing $f$ on $U$ by the map $\phi^{-1}\circ B_U\circ \phi$ and keeping $f$ outside $U$, it follows from the \BlogPost{third-surgery}{Gluing Lemma} that we obtain a new quasirational map. If $p>1$ then we have to replace $f$ on the disc components $U_j$ where $I(U_j):= \hat{f}^j(I(U))$ for $0\leq j\leq p-1$ with maps that are compatible with $\hat{f}$ along the ideal boundaries and whose composition agrees with $\phi^{-1}\circ B_U\circ \phi$ on $U$. Set $U_0=U$ and $U_p=U_0$. Let $d_j\geq 1$ denote the degree of $\hat{f}:I(U_j)\rightarrow I(U_{j+1})$ for $0\leq j\leq p-1$. Then the product $\prod_{j=0}^{p-1}{d_j} = d$, where $d=1$ in the elliptic case. From Proposition $6.16$ $(3)$ we know that there exists a pair of quasisymmetric maps mapping $I(U_j)$ and $I(U_{j+1})$ respectively to $\mathbb{S}^1$ and providing an equivalence between $\hat{f}$ and $B_j(z):= z^{d_j}$ for $0\leq j\leq p-2$. From what we noted in Proposition $6.16$ we know that we may choose one of the quasisymmetric maps arbitrarily. Let $\hat{\phi}_0 = \hat{\phi}:I(U_0)\rightarrow \mathbb{S}^1$ from above and let $\phi_0=\phi$. For $j = 1,\ldots, p-1$ establish recursively $\hat{\phi}_j:I(U_j)\rightarrow \mathbb{S}^1$ such that $\hat{\phi}_j\circ \hat{f} = B_{j-1}\circ \hat{\phi}_{j-1}$. Extend $\hat{\phi}_1,\ldots,\hat{\phi}_{p-1}$ quasiconformally over their disks and denote the extensions by $\phi_1,\ldots,\phi_{p-1}$. Finally set $\phi_p=\phi_0$. Depending on the case we choose $B_{p-1}$ to be the Blaschke product defined as

    \includegraphics[width=.95\linewidth]{ms-fig-28.pdf}
    \FigureTag{MS28}{fig:ms-28}
    \end{figure}

    $$B_{p-1}(z):= \begin{cases}
        e^{2\pi i \theta}z, &\quad\text{in the elliptic case,}\\
        z^{d_{p-1}} &\quad\text{in the hyperbolic case,}\\
        \frac{z^{d_{p-1}}+a}{1 + az^{d_{p-1}}} &\quad\text{in the parabolic case, for}   a = \frac{d-1}{d+1}\\
        \end{cases}$$

    With $B_j(z)=z^{d_j}$ for $0\leq j\leq p-2$, the corrected telescoping identity behind the source's factor table is
    \[
    g^{\circ p}\big|_{U_0}
      =\phi_0^{-1}\circ
        \bigl(B_{p-1}\circ B_{p-2}\circ\cdots\circ B_0\bigr)
        \circ\phi_0,
    \qquad d=\prod_{j=0}^{p-1}d_j.
    \]
    The model factors are displayed together as
    \[
    \begin{array}{c|ccccc}
    B_U&B_{p-1}&B_{p-2}&B_{p-3}&\cdots&B_0\\ \hline
    e^{2\pi i\theta}z&e^{2\pi i\theta}z&z&z&\cdots&z\\
    z^d&z^{d_{p-1}}&z^{d_{p-2}}&z^{d_{p-3}}&\cdots&z^{d_0}\\
    P_d&M_a\circ(z\mapsto z^{d_{p-1}})&z^{d_{p-2}}&z^{d_{p-3}}&\cdots&z^{d_0}
    \end{array}
    \]
    where $M_a(z)=(z+a)/(1+az)$ and $a=(d-1)/(d+1)$. This corrects the source's use of a sum of degrees and its mismatched $B_p$ indices.


    The conditions in \BlogPost{third-surgery}{Corollary $6.13$} are therefore satisfied. Hence, by replacing $f$ on $U_j$ by the map $\phi_{j+1}^{-1}\circ B_j\circ \phi_j$ for $j = 0, 1, \ldots, p-1$ and keeping $f$ outside $\bigcup_{j=0}^{p-1}{U_j}$ we obtain a new quasirational map.\\
    After having dealt with all the periodic components of $I(C)$ we work backwards along the preimages of each of them. If $I(V)$ is one of them, and $\hat{f}(I(V)) = I(W)$, then $\hat{f}$ is quasisymmetrically equivalent to $z\rightarrow z^d$ for some $d\geq 1$. If $d=1$ we keep the conformal isomorphism $f\big|_V:V\rightarrow W$. Only if $d>1$ shall we replace the map. Suppose this has been done up to $V$. We construct as before gluing maps $\phi_1$ and $\phi_2$ using Riemann mappings $R_V$ and $R_W$, and define the new map on $V$ by $\phi_2^{-1}\circ z^d\circ \phi_1$. The new critical point $c$ equals $\phi_1^{-1}(0) \in V$, with critical value equal to $\phi_2^{-1}(0)$. The orbit of $c$ satisfies one of the conditions in the main theorem if the orbit of its critical value does. We choose the Riemann mapping $R_W$ so that $\phi_2^{-1}(0)$ has the correct orbital behaviour. Keep repeating this. By Proposition $6.16$ (1), after a finite number of steps we have constructed a quasirational map $q$ satisfying the conditions of the main theorem. After integration, let $\Phi$ be a quasiconformal map such that $\Phi\circ q=g\circ\Phi$ for the desired rational map $g$.\\

    Now, to prove that the set carried over from $C$ is exactly the Julia set of $g$, first note that $q$ agrees with $f$ on $C$ and satisfies $q^{-1}(C)=C$. Set $F=\Phi(C)$. Then $(C,f)\sim(F,g)$, and $F$ is a connected, nowhere dense, totally invariant set for $g$. We must show that $F=J(g)$. It is enough to show that the boundaries of the periodic components of $\hat{\mathbb{C}}\backslash F$ lie in $J(g)$, since their grand orbits are dense in $F$. This is clear for the hyperbolic and parabolic models. In the elliptic case, the only obstruction would be that $g$ is an irrational rotation of the whole Riemann sphere and $F$ is an invariant circle. But this would force $C$ to be a quasicircle bounding a Siegel disk or Herman ring on both sides. The iterates of $f$ would then form a normal family on an annular neighbourhood of $C$, contradicting the fact that $C$ is a component of the Julia set. Hence $F=J(g)$.

    The preceding lemmas prove Proposition $6.17$, and the surgery construction proves Theorem $6.15$. Therefore, the stable conjugacy establishes the isomorphism $\text{Mod}(C, f) \cong \text{Mod}(J(g), g)$ and proves Theorem $6.3$ (1). The following proposition shall handle Theorem $6.3$ (2), thereby finishing the proof of the central theorem behind this surgery.
