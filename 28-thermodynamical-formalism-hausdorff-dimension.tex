\section*{Thermodynamical Formalism and Hausdorff Dimension}
% BLOG-CONTENT-BEGIN

How does thermodynamical formalism help us understand Hausdorff dimension? Our motivation is to understand \cite{denker1991hausdorff} and to be equipped enough to extend its results to larger classes of functions wherein the conventional methods introduced by Bowen et al. fail. 
\section{Overview of Ergodic Theory}
Given an object of a category with a self-morphism, we wish to study its evolution. If the object were a set $X$ with a group of automorphisms $G$, then we are in the realm of group actions. If $X$ were a compact metric space with $T$ a continuous endomorphism, then we are dealing with topological dynamical systems. One can endow $X$, $T$, and $G$ with more refined structures and study the same. Finally, if $(X, \mu)$ were a probability space and $T$ a measure preserving transformation (i.e. $\mu(B) = \mu(T^{-1}(B))$), then the study of the evolution of the system $(X, \mu, T)$ is called ergodic theory\footnote{For a complete treatment of the ideas exposed in this section, we refer the reader to \cite{einsiedler2011ergodic}}. One can think of $T$ as a deterministic link connecting the likelihood of occurrence of $B$ with $T^{-1}(B)$. 

\underline{\textbf{Examples :-}} 
\begin{enumerate}
    \item $(\mathbb{R}/\mathbb{Z}, \text{Lebesgue}, t\rightarrow t+\alpha)$
    \item $(\mathbb{R}/\mathbb{Z}, \text{Lebesgue}, t\rightarrow 2t)$
    \item $(\{0,1\}^{\mathbb{N}}, \prod_{\mathbb{N}}\mu_{\frac{1}{2}}, (x_0, x_1, \ldots) \rightarrow (x_1, x_2, \ldots))$ where $\mu_{\frac{1}{2}}(\{0\}) = \mu_{\frac{1}{2}}(\{1\}) = \frac{1}{2}$.
\end{enumerate}

We ask two fundamental questions about the evolution of a given measure preserving system $(X, \mu, T)$.\\


1) What happens to $\{T^{\circ n}(x)\}_n$ or $\{T^{\circ n}(E)\}_n$ as $n\rightarrow \infty$?


2) What happens to $\{f\circ T^{\circ n}(E)\}_n$, for $f:X \rightarrow \mathbb{C}$, measurable, as $n\rightarrow \infty$? 

The answer to the first question leads us to the notions of recurrence and ergodicity. 
\subsection*{Theorem 2.1 — Poincare Recurrence} Given a measure preserving system $(X, \mu, T)$, and a measurable set $B$, with $\mu(B) >0$, then, 
$$\big|\{T^{\circ n}(x)\}_n\cap B\big| = \infty$$

for a.e $x\in B$. Said plainly, the orbit of almost all $x\in B$ recurs in $B$ infinitely often.


Picking off from the theorem above we ask if the same holds for $x\notin B$. Phrased differently, can $T$ make $x$ land in $B$? Note that, there is an obvious set theoretic restriction stopping us from answering the question in the affirmative. That is, if $T^{-1}(B) = B$, then $\{T^{\circ n}(E)\}_n \cap B = \emptyset$, $\forall x\notin B$. Keeping this restriction in mind, let us define the following,
\subsection*{Definition 2.1}
    A measure preserving system $(X, \mu, T)$ is said to be \textbf{ergodic}, if $\forall B$, $T^{-1}(B) = B$, implies $\mu(B) \in \{0,1\}$. 


Clearly, ergodic systems (defined above) have bypassed the set-theoretic restriction, and turns out that now recurrence holds in a larger sense,
$$\text{if }\mu(B)>0, \text{ then } \mu\Bigg(\bigcup_{n=1}^{\infty} T^{-n}(B)\Bigg) = 1$$


That takes care of the qualitative descriptions. Now, to describe the same quantitatively, one needs to be able to do analysis (calculus) on measure-preserving systems. This attempt would also be fruitful for answering the second question. To do analysis, we set up the following dictionary,
\begin{itemize}
    \item $L^2(\mu) \longleftrightarrow (X,\mu)$ (replace $X$ with a naturally occurring Hilbert space).
    \item $U_T \longleftrightarrow T$ (erect an operator $U_T$ on that Hilbert space).
    \item $\big(U_T:L^2(\mu) \rightarrow L^2(\mu)\big)\longleftrightarrow \big(T:X\rightarrow X\big)$ (study the action of $T$ on $X$ by studying the same of $U_T$ on $L^2(\mu)$).
\end{itemize}

Here, $U_T(f):= f\circ T$ is called the Koopman operator. Let $f_1, f_2 \in L^2(\mu)$, then,
$$\langle U_Tf_1, U_Tf_2\rangle := \int_X (f_1\circ T)\overline{(f_2\circ T)}d\mu = \int_Xf_1\overline{f_2}d\mu$$

as $T$ is measure preserving, this implies, 
$$\langle f_1, (U_T^*U_T-\text{Id})f_2\rangle = 0$$

which forces, 
$$\sup_{||f_1||, ||f_2||\leq 1} \bigg(\big|\langle f_1, (U_T^*U_T-\text{Id})f_2\rangle\big|\bigg) = ||U_T^*U_T-\text{Id}|| = 0$$

Therefore, $U_T$ is unitary. The following theorem describes ergodicity from an operator theoretic perspective. 
\subsection*{Theorem 2.2}
    $(X, \mu, T)$ is ergodic iff $U_T(f) = f$ implies $f$ is some constant function $c$.


The answers to the second question appear as ergodic theorems. The common feature of these theorems is that they all study the quantity,
$$A_N^f:= \frac{1}{N}\sum_{n=0}^{N-1}U_T^n(f)$$

as $N \rightarrow \infty$. We shall list those theorems now.
\subsection*{Theorem 2.3 — von-Neumann Ergodic Theorem} Let the following be a projection operator,
$$P_T:L^2(\mu) \rightarrow \{g\in L^2(\mu)  | U_Tg= g\}$$

then, $\forall f\in L^2(\mu)$, 
$$A_N^f \rightarrow P_T(f)$$

in the $L^2$-norm.

\subsection*{Theorem 2.4 — Mean Ergodic Theorem} Given $f \in L^1(\mu)$, we have,
$$A_N^f \rightarrow f' (\in L^1(\mu))$$

in the $L^1$-norm, where $U_Tf' = f'$. 

As we have the following containment,
$$L^{\infty}(\mu) \subseteq \cdots \subseteq L^2(\mu) \subseteq L^1(\mu)$$

we see that Theorem $2.4$ extends Theorem $2.3$. 
\subsection*{Theorem 2.5 — Birkhoff's Ergodic Theorem} If $f \in L^1(\mu)$, then,
$$A_N^f(x) \rightarrow f^*(x)$$

point-wise. Further, $f^* \in L^1(\mu)$, $U_Tf^* = f^*$, and,
$$\int_Xf^*d\mu = \int_Xfd\mu$$

\textbf{Remark 2.1.} If $(X,\mu, T)$ is ergodic, then $f^* = c$, and this implies, 
$$\int_Xf^*d\mu = c = \int_Xfd\mu$$

Therefore, 
$$\lim_{n\rightarrow\infty} \bigg(\frac{1}{n}\sum_{i=0}^{n-1}f(T^i(x))\bigg) = \int_Xfd\mu$$

If $f = \chi_A$, then $A_N^f$ is the average number of times $T^{\circ n}(x)$ hits $A$, also called the time-average. The right-hand side of the equality (above) represents space-average. Therefore, Birkhoff's theorem stands to show a duality between time and space averages.

\textbf{Remark 2.2.} If $T$ was ergodic, then by dominated convergence theorem, for $f, g \in L^1(\mu)$,
$$\frac{1}{N}\sum_{n=1}^{N-1}\langle f\circ T^n, g\rangle \rightarrow \Bigg(\int_Xfd\mu\Bigg)\Bigg(\int_X\overline{g}d\mu\Bigg)$$

Set, $f = \chi_A$, $g= \chi_B$, then,
$$\frac{1}{N}\sum_{n=1}^{N-1}\mu(A\cap T^{-n}(B)) \rightarrow \mu(A)\mu(B)$$

It is easy to show that the condition above is equivalent to ergodicity. So, the point is, if $A$ and $T^{-n}(B)$ were independent, then,
$$\mu(A\cap T^{-n}(B)) = \mu(A)\mu(T^{-n}(B) = \mu(A)\mu(B)$$

Inferred in that sense, ergodic maps are trying to separate events $\{T^{-n}(B)\}_n$ from $A$ (on average). Having identified this feature of ergodicity, one can try to strengthen it further and study it. The following two definitions are relevant in that sense. 
\subsection*{Definition 2.2}
    Given measurable sets $A, B$, if,
    $$\mu(A\cap T^{-n}(B)) \rightarrow \mu(A)\mu(B)$$
    
    then, $(X, \mu, T)$ is called a \textbf{mixing system}.

\subsection*{Definition 2.3}
    Given measurable sets $A, B$, if,
    $$\frac{1}{N}\sum_{n=1}^{N-1}|\mu(A\cap T^{-n}(B)) -\mu(A)\mu(B)| \rightarrow 0$$
    
    then, $(X, \mu, T)$ is called a \textbf{weakly mixing system}.


By Koopman-Neumann Lemma, one can show that the condition for a system to be weakly mixing is equivalent to,
$$\mu(A\cap T^{-n}(B)) \rightarrow\mu(A)\mu(B)$$

as $n\rightarrow \infty$, $n\notin J$, where $J$ has density $0$\footnote{density$(J):= \lim_{n\rightarrow\infty} \frac{|J\cap [1, n]|}{n}$}.

In summary, ergodic systems separate events on average, weakly ergodic systems separate events asymptotically (except on a density zero set), and mixing systems separate events asymptotically; giving us the following containment,
$$\text{Mixing } \subset \text{ Weakly Mixing } \subset \text{ Ergodic}$$


Let us now apply the tools developed thus far to understand topological dynamical systems. Recall, that this new setting consists of a compact metric space $(X, d)$, and a continuous self-map $T:X\rightarrow X$. To proceed one must induce the structure of a measure-preserving system on $(X, d, T)$. Riesz representation theorem tells us that the following is a bijective correspondence,
$$\big(\Lambda \in C(X)^*\big) \longleftrightarrow \Bigg(f\rightarrow \int_Xfd\mu\Bigg)$$

Let $M(X)$ be the space of probability measures on $X$, which by the correspondence above can be identified with functionals on $C(X)$ with $*$-topology. Observe the following,
\begin{enumerate}
    \item Given a sequence $\{\mu_n\}_n$ from $M(X)$, with $\mu_n\rightarrow \mu$, we have, 
    $$\int_Xfd\mu_n \rightarrow \int_Xfd\mu$$
    
    If $f \equiv 1$, then $\mu(X) = 1$, and similarly one can also prove that $\mu > 0$. Therefore, $M(X)$ is closed.
    \item As $X$ is compact, the following holds,
    $$\Bigg|\int_xfd\mu\Bigg|\leq ||f||_{\infty}\int_X1d\mu$$
    
    which implies that $||\mu|| \leq 1$, giving us that $M(X)$ is bounded.
    \item By Banach-Alaglou Theorem, $M(X)$ is compact.
\end{enumerate}


Turns out that, 
$$M^T(X) := \{\mu\in M(X) |  \mu \text{ is }T-\text{invariant}\}$$

also satisfies $(1), (2), $ and $(3)$. These properties yield the following theorems.
\subsection*{Theorem 2.6}
    $M^T(X) \neq \emptyset$. That is, one can do ergodic theory on $X$

\subsection*{Theorem 2.7}
    Ergodic elements of $M^T(X)$ are its extreme points (call it $E^T(X))$.

\subsection*{Theorem 2.8 — Ergodic Decomposition} Given $(X, d, T)$, $\mu\in M^T(X)$, there exists unique $\lambda$ on $E^T(X)$ such that,
\begin{itemize}
    \item $\lambda(E^T(X)) = 1$
    \item The following convex linear integral representation holds,
    $$\int_Xfd\mu = \int_{E^T(X)}\bigg(\int_Xfd\nu\bigg)d\lambda$$
\end{itemize}

This has a couple of consequences for our topological dynamical system, which we shall now state.
\subsection*{Theorem 2.9 — Unique Ergodicity}
$A_N^f(x) \rightarrow C_f$

is independent of $x$ ($\forall f \in C(X)$) iff $|M^T(X)| =1$.

The second consequence is that it allows us to introduce a notion of a bunch of points in $X$ being spread across uniformly. 
\subsection*{Definition 2.4}
A sequence $\{x_n\}_n \subset X$ is said to be \textbf{equidistributed} in $(X, d, T, \mu)$, if $\forall f\in C(X)$, 
$$\lim_{n\rightarrow \infty} \frac{1}{n}\sum_{i=1}^{n}f(x_i) = \int_Xfd\mu$$

Further, $x\in X$ is said to be \textbf{generic} if $\{T^{\circ n}(x)\}_n$ is equidistributed.

\subsection*{Theorem 2.10}
    $\mu\in M^T(X)$ is ergodic implies that almost every $x\in X$ is generic. 


To summarize, in this overview, we introduced ergodic theory as a study of the evolution of a measure-preserving system. Then we posed questions about orbits; whose answers featured in as recurrence theorems and ergodic theorems. We applied that knowledge to the setting of a topological dynamical system and found a way to make sense of equidistribution.   

\section{Overview of Entropy}
Suppose we have a bunch of events labeled $A_1, A_2, \ldots, A_n$, with probabilities $p_1, p_2, \ldots, p_n$. If $p_1$ was $99\%$, and the remaining $1\%$ was distributed among $\{p_i\}_{i>1}$, then, there's hardly any uncertainty in the system. Whereas if $p_i = 1/n$, ($\forall i,$ $1\leq i\leq n$), then the system is highly unstable. We ask: How to quantify the above phenomenon? A bunch of axioms of the function $H(p_1, p_2,\ldots, p_n)$ that describes the stability of the phenomenon (above), as a function of the probabilities becomes evident. We list them now,

\begin{enumerate}
    \item If $f(N):= H(1/N, 1/N, \ldots, 1/N)$, then $f$ is decreasing.
    \item $f(ML) = f(M) + f(L)$
    \item $H(p_1, \ldots, p_n) = h(p_A, p_B) + p_AH(p_1/p_A, \ldots, p_r/p_A) + p_BH(p_{r+1}/p_B, \ldots, p_N/p_B)$, where $A$ is the collection of the events $A_1, \ldots, A_r$, and $B$ is the collection of the remaining events.
    \item The function $p\rightarrow H(p, 1-p)$ must be continuous on $(0,1)$.
\end{enumerate}

The axioms above roughly capture our intuition on uncertainty: As $N$ increases, the fact that we demand $f(N)$ to decrease captures the fact that each outcome has almost no chance of occurring, hence inviting no dynamic expectation regarding the outcome. Axiom $2$ talks about a scenario in which there are $M$, $L$ events (each equally likely), and we are to choose one from the set of $M$ events, and the other from the set of $L$. In all, there are $ML$ equally likely choices. We demand the complexities of the two choices, captured by $f(M)$ and $f(L)$, to add up to $f(ML)$, to indicate that one choice does not affect the other in any quantifiable way; they simply add up. Axiom $3$ is just a strengthening of the scenario that Axiom $2$ addresses, namely, suppose the first choice is made with probability $p_A$, and the second with probability $p_B$, and further that the events are not equally likely, then we demand the uncertainties to add up like above. The rationalization for Axiom $3$ can be extrapolated from that of Axiom $2$. Finally, Axiom $4$ is a regularity demand which captures the nature of the uncertainties not having strange jumps (or discontinuities). The upshot of these Axioms is the following theorem.
\subsection*{Theorem 3.1}
    The functions satisfying Axioms $1, 2, 3, 4$ are all of the form,
    $$H(p_1, p_2, \ldots, p_n) = -c\sum_{i=1}^np_i\log{p_i}$$


One can use this to inform our choices for a general probability space $(X,\mu)$. 
\subsection*{Definition 3.1}Let $\alpha = \{A_1, A_2\ldots\}$ be a finite or countable partition of $X$. The \textbf{information function} of $\alpha$ is defined to be,
$$I(\alpha)(x):= -\sum_{A\in \alpha}\chi_A(x)\log{\mu(A)}$$  

\subsection*{Definition 3.2}
    With $\alpha$ as above, the \textbf{entropy} of $\alpha$ is defined to be,
    $$H(\alpha):= -\int I(\alpha)d\mu = -\sum_{A\in \alpha}\mu(A)\log{\mu(A)}$$


The information function captures the complexity of information in $\alpha$ that shall be exploited to narrow down the location of the point $x\in X$. If we are to search for $x$ in a partition where each part is large, then of course, the information is rather vague: which is why the function $\chi_A(x)$ is weighted by $\log{1/\mu(A)}$. And entropy captures the average complexity of the information function. Now suppose, $\mathcal{A} \subseteq \mathcal{B}$ is a $\sigma$-subalgebra, then for any $f\in L^1(\mu)$, we have, 
$$\Bigg(\int_Xfd\big(\mu|_{\mathcal{A}}\big)\Bigg) \ll \mu$$

Let $E(f|\mathcal{A})$ be its Radon-Nikodym derivative. We now have an operator, 
$$E(\cdot|\mathcal{A}):L^1(\mu) \rightarrow L^1(\mu|_{\mathcal{A}})$$

such that, $\forall A\in \mathcal{A}$, and $\forall f\in L^1(\mu)$
$$\int_AE(f|\mathcal{A})d\mu|_{\mathcal{A}} = \int_Afd\mu$$

\subsection*{Definition 3.3}
    The \textbf{conditional probability} of $B\in \mathcal{B}$ given $\mathcal{A}$ is,
    $$\mu(B|\mathcal{A}) := E(\chi_B|\mathcal{A})$$

\subsection*{Definition 3.4}
    The \textbf{conditional information function} of $\alpha$ given $\mathcal{A}$ is,
    $$I(\alpha|\mathcal{A})(x):= -\sum_{A\in \alpha}\chi_A(x)\log{\mu(A|\mathcal{A})}$$
    
    and the \textbf{conditional entropy} of $\alpha$ is defined to be,
    $$H(\alpha|\mathcal{A}):= -\int I(\alpha|\mathcal{A})d\mu = -\sum_{A\in \alpha}\mu(A|\mathcal{A})\log{\mu(A|\mathcal{A})}$$


Now, let us upgrade our situation to a measure-preserving system $(X, \mu, T)$. Keeping in mind the terms introduced, we want to capture the complexity of the evolution induced by $T$ in $(X, \mu)$. Now, the information given by $\alpha$ to locate $x\in X$ is not absolute, for one can use $T$. Denote by $T^{-1}\alpha$ the partition $\{T^{-1}(A)\}_{A\in \alpha}$. For partitions $\alpha_1, \alpha_2$, denote by $\alpha_1\vee\alpha_2$ the partition $\{A_1\cap A_2\}_{A_i\in \alpha_i}$. Write,
$$H_n(\alpha) := H\Bigg(\bigvee_{i=0}^{n-1}T^{-1}\alpha\Bigg)$$

indicating the entropy of the system when the operator $T$ is put to use $n$ times. Putting the operator to use is not independent of its previous use as far as entropy is concerned, for the equality $H_{n+m}(\alpha) = H_{n}(\alpha) + H_{m}(\alpha)$ is not true. What is true is that the sequence $\{H_n(\alpha)\}_n$ is sub-additive, that is, 
$$H_{n+m}(\alpha)\leq H_{n}(\alpha) + H_{m}(\alpha)$$ 

One defines the entropy of $T$ relative to $\alpha$ as the asymptotic average of entropies obtained by putting $T$ to use $n$ times, that is, the quantity, 
$$\lim_{n\rightarrow \infty} H_n(\alpha)$$
for two reasons: (a) to make use of $T$ fully, and (b) to make things independent of $n$. Further, the sub-additivity of the sequence guarantees the existence of the proposed limit\footnote{one can see the same via Martingale Convergence Theorem \cite{durrett2019probability}.}.
\subsection*{Definition 3.5}
    The \textbf{entropy of a measure-preserving transformation $T$ relative to a partition $\alpha$} is defined to be,
    $$h_{\mu}(T, \alpha):= \lim_{n\rightarrow\infty}\frac{1}{n}H\Bigg(\bigvee_{i=0}^{n-1}T^{-1}\alpha\Bigg)$$

\subsection*{Definition 3.6}
    The \textbf{entropy of the measure-preserving system $(X, \mu, T)$} is defined to be, 
    $$h_{\mu}(T) := \sup_{\alpha}h_{\mu}(T, \alpha)$$
    
    where $\alpha$ is a countable partition of $X$ with measurable parts.


In practice, computing entropy of $(X, \mu, T)$ could turn out to be a pain in the neck given the nature of the definition. But, the following two theorems (attributed to Abramov and Sinai) come to our rescue.
\subsection*{Theorem 3.2 — Abramov}
    Suppose $\alpha_n\uparrow \mathcal{B}$ are countable partitions with $H(\alpha_n)<\infty$ ($\forall n$, $n\geq 1$). Then,
    $$h_{\mu}(T) = \lim_{n\rightarrow\infty}h_{\mu}(T, \alpha_n)$$

\subsection*{Theorem 3.3 — Sinai}Set, 
$\alpha^n := \alpha\vee T^{-1}\alpha\vee\cdots\vee T^{-(n-1)}\alpha$. Suppose $\alpha^n \rightarrow \mathcal{B}$\footnote{such an $\alpha$ is called a \textbf{strong generator} for $\mathcal{B}$.}, or that $T$ is invertible. If $H(\alpha) <\infty$, then,
$$h_{\mu}(T) = h_{\mu}(T, \alpha)$$


The following theorem attributed to Shannon, McMillan, and Breiman illustrates a way to compute $h_{\mu}(T, \alpha)$ given a countable partition $\alpha$ with finite entropy. 
\subsection*{Theorem 3.4 — Shannon-McMillan-Breiman} For a countable partition $\alpha$ with finite entropy, the following limits exist, 
$$f = \lim_{n\rightarrow\infty}I\Bigg(\alpha\Bigg|\bigvee_{i=1}^nT^{-i}\alpha\Bigg)$$\footnote{here we mean to say that $f$ is the limit of the conditional information function given the sigma algebra generated by the latter partition.}
$$f_I(x) =\lim_{n\rightarrow\infty}\frac{1}{n}\sum_{i=1}^{n-1}f(T^i(x)) \text{ (for a.e. }x)$$

and,
$$f_I = \lim_{n\rightarrow\infty} \frac{1}{n+1}I(\alpha^n) \text{a.e. and in }L^1$$

Furthermore, 
$$h(T, \alpha) = \lim_{n\rightarrow\infty} \frac{1}{n+1}H(\alpha^n) = \int f_Id\mu = \int fd\mu$$

\subsection*{Theorem 3.5 — Shannon-McMillan-Breiman, ergodic case} If $(X, \mu, T)$ is ergodic with countable partition $\alpha$ having finite entropy, then, 
    $$h_{\mu}(T, \alpha) = \lim_{n\rightarrow\infty} \frac{1}{n}T(\alpha^n)(x) \text{ for a.e. }x$$


The entropy of a probability space measured the uncertainty, or the average complexity of the information function. In other words, it featured as a potential for the information function. Having performed the jugglery to introduce a notion of entropy for a measure-preserving system, we ask if it is a potential of some function. To answer that question we define the following notion.
\subsection*{Definition 3.7}
    Let $(X, \mu)$ and $(X', \mu')$ be probability spaces. Let $T:X\rightarrow X'$ be a measurable map. We say a function $J$ is a \textbf{weak Jacobian} if there exists a measure $0$ set $E$ such that for all $A \subset X\backslash E$, on which $T$ is injective, the set $T(A)$ is measurable and,
    $$\mu(T(A)) = \int_AJd\mu$$
    
    We say, $J$ is a \textbf{Jacobian}, if the above holds for all $A\subset X$.

\subsection*{Theorem 3.6 — Rokhlin's Entropy Formula} Let $(X, \mu, T)$ be a measure-preserving system and a Lebesgue space, where $T$ is essentially countable to one\footnote{for details on the hypotheses refer \cite{przytycki2010conformal}}. Suppose that on each component $A$ of the ergodic decomposition, the restriction $T_A$ has a countable one-sided generator of finite entropy. Then,
$$h_{\mu}(T) = \int \log{J_{\mu}}d\mu$$


In short, the entropy of a measure-preserving system $(X, \mu, T)$ is trying to capture the average logarithmic rate of expansion of the endomorphism $T$. Now like in the previous section, one can take this to the setting of a topological dynamical system, and define what's called a topological entropy, but we shall refrain from doing that here for the sake of brevity. We refer the reader to \cite{viana2016foundations} for excellent coverage of the same. For a complete treatment of ideas in this section, look at \cite{przytycki2010conformal}.

\section{Gibbs Measure}
In this section, we shall give an overview of Gibbs measure (for details refer \cite{przytycki2010conformal}), and explain its relevance to the pressure functional. The setting of our story is the following:-

\begin{enumerate}
    \item $X$, a compact metric space (with metric $\rho$)
    \item $T$, an open continuous distance expanding map (topologically transitive)
    \item $\varphi \in C(X)$, is Holder continuous.
\end{enumerate}
we shall specialize the setting later, for now, let's work in this generality. Before proceeding, let us remark some things about the setting.

First, note that $T:X \rightarrow X$ is a covering map, for one can show that it is a proper local homeomorphism. Further, one can find $\eta$, and $\xi$ such that:-
\begin{itemize}
    \item $\rho(x, y)\leq 2\eta$ implies $\rho(T(x), T(y)) \geq \lambda\rho(x, y)$
    \item $\rho(x, y)\leq 2\xi$ implies $\rho(T_1^{-1}(x), T_1^{-1}(y)) \leq \frac{1}{\lambda}\rho(x, y)$ where $T_1$ is $T$ restricted to the first slice of the evenly covered neighborhood given by the ball of radius $2\xi$ around $x$.
    \item $B(T(x), \xi) \subset T(B(x, \eta))$
\end{itemize}


Also, if $T$ is open continuous and distance expanding, then, 
$$\mu \in M(X, T) \rightarrow h_{\mu}(T)$$
is upper semi-continuous, which implies that the entity (called the pressure of $\varphi$)\footnote{for more information on pressure functionals refer to \cite{viana2016foundations}},
$$P(T, \varphi):= \sup_{\mu \in M(X, T)} \bigg\{h_{\mu}(T) + \int_X\varphi d\mu \bigg\}$$
attains its supremum.


Further, if $\varphi: X \rightarrow \mathbb{R}$ is Holder continuous then,
$$P(T, \varphi) = \lim_{n\rightarrow\infty} \frac{1}{n}\log\Bigg(\sum_{\overline{x} \in T^{-n}(x)}\text{exp}(S_n(\varphi(\overline{x})))\Bigg)$$
where $S_n(\varphi) \equiv \varphi + \varphi\circ T + \cdot + \varphi\circ T^{n-1}$, and set $\widetilde{\varphi} = \text{exp}(S_n(\varphi))$. It can be shown that for the following sequence of measures,
$$\mu_n:= \frac{\sum_{\overline{x} \in T^{-n}(x)}\delta_{x}\widetilde{\varphi}(\overline{x})}{\sum_{\overline{x} \in T^{-n}(x)}\widetilde{\varphi}(\overline{x})}$$
every weak limit of 

$$\Bigg\{\frac{1}{n} \sum_{k = 0}^{n-1}\mu_n\circ T^{-k}\Bigg\}_n$$
is an equilibrium/maximal measure. Characterization of these maximal measures falls in the realm of thermodynamic formalism.

\subsection*{Definition 4.1}
    Let $\mu$ be a Borel probability measure, then $\mu $ is said to be a Gibbs state (or measure) for $\varphi \in C(X)$ if there exists $C \geq 1$ such that $\forall n \geq 1$

    $$ \frac{1}{C}\leq \frac{\mu(T_x^{-n}(B(T^n(x), \xi)))}{\text{exp}\big(S_n(\varphi(x)) - P(T, \varphi)n\big)} \leq C$$
    
    (here $T_x$ is the inverse branch of $T$ to the slice that contains $x$)

\subsection*{Theorem 4.1}
    A $T$-invariant Gibbs state $\mu$ for $\varphi$ is an equilibrium measure.

\textit{Proof.}
    Let $\alpha$ be a partition of $X$ into Borel sets of diameter less than $\min(\eta, \xi)$ (a small enough Markov partition would work for instance), then one can show that, 
    $$\alpha^n(x) \subset T_x^{-n}(B(t^n(x), \eta))$$
    Now by Shannon-McMillan-Brieman Theorem,
    $$h_{\mu}(T) \geq h_{\mu}(t, \alpha) = \int\lim_n \frac{1}{n}\mathcal{I}(\alpha^n)d\mu$$
    this gives, 
    $$h_{\mu(T)}\geq \int\lim_n \frac{1}{n}\mathcal{I}(\alpha^n)d\mu \geq \int \lim_n \frac{1}{n}\bigg(nP(T, \varphi) - S_n(\varphi(x))\bigg)d\mu = P(T, \varphi) - \int_X \varphi d\mu$$
    Conclusively yielding, 
    $$P(T, \varphi) \leq h_{\mu}(T) + \int_X\varphi d\mu$$


Now one can ask if such measures exist, and if it does, is it unique? That's where Ruelle's transfer operator plays a role (more about this in the next section). Let us introduce these operators.

\subsection*{Definition 4.2}
    Ruelle's transfer operator for $\varphi \in C(X)$ is a linear endomorphism on $C(X)$, and is given explicitly by,
    $$L_{\varphi}(u)(x):= \sum_{\overline{x}\in T^{-1}(x)}u(\overline{x})\text{exp}(\varphi(\overline{x}))$$
    and its dual $L_{\varphi}^*$ can be thought of as a linear endomorphism on the space of regular Borel measures on $X$ (by the Riesz Representation Theorem) 

One has the following central theorem that dictates most of what happens in thermodynamic formalism.
\subsection*{Theorem 4.2 — Perron-Frobenius-Ruelle}
Keeping the setting and the notation introduced in mind the following statements hold:-
\begin{enumerate}
    \item There exists a simple eigenvalue $\beta > 0$ of $L_{\varphi}$ and an associated eigenvector $h_{\varphi} > 0$ in $C(X)$. 
    \item There exists a unique probability measure $\mu_{\varphi}$ on $X$ such that $L_{\varphi}^*(\mu_{\varphi}) = \beta\mu_{\varphi}$, and $\forall$ $v \in C(X)$,
    $$\frac{L_{\varphi}^n(v)}{\beta^n} \rightarrow \frac{h\int vd\mu_{\varphi}}{\int hd\mu_{\varphi}}$$
    \item $\beta = P(T, \varphi)$
\end{enumerate}


Using this one can show that $\varphi$ has a unique Gibbs state which is explicitly given by $h_{\varphi}\mu_{\varphi}$. This is the spectral description of maximal measures and should be seen as analogous to such descriptions of ergodic measures using the Koopman operator. In fact, in a certain setup, the Koopman operator turns out to be the adjoint of the Ruelle operator. This brings us to a final question of this section:- Are all equilibrium measures Gibbs state? - we shall record the answer to that as a theorem.

\subsection*{Theorem 4.3}
    All equilibrium measures are Gibbs states.

\textit{Proof.}
    Let $\nu$ be an equilibrium state for $\varphi$, then set, 
    $$\Psi = \varphi - P(T, \varphi) + \log(h_{\varphi}\circ T) - \log(h_{\varphi})$$
    one can now show (with some effort)
    $$\nu(T_z^n(B(T^n(z), \xi))) = \int_{B(T^n(z), \xi)} \text{exp}(S_n\Psi(T_z^{-n}(x)))d\nu (x)$$
    there's another lemma (called Pre-Bounded Distortion Lemma) which shall feature in (the proof can be found in any standard text on Gibbs measure)
    $$\frac{\sum_{\overline{x}\in T^{-n}(x)}\widetilde{\varphi}(x)}{\sum_{\overline{y}\in T^{-n}(y)}\widetilde{\varphi}(y)} < C   (\forall x, y \in X)$$
    these in conjunction imply,
    $$\Bigg(\frac{\inf |h_{\varphi}|}{\sup |h_{\varphi}|}B\Bigg)\frac{1}{C} \leq \frac{\nu(T_x^{-n}(B(T^n(x), \xi)))}{\text{exp}\big(S_n(\varphi(x)) - P(T, \varphi)n\big)} \leq \Bigg(\frac{\sup |h_{\varphi}|}{\inf |h_{\varphi}|}\Bigg) C$$
    where $B = \inf_{\xi}\{\nu(B(y, \xi))$. It remains to show that $B >0$. Here we will use the fact that $T$ is topologically transitive. Let $U \subset_{\text{open}} X$, then,
    $$\bigcup_{j = 0}^{n}T^j(U) = X$$
    for some $n$. Also, a small lemma involving Jacobians would tell you that $\nu(U) > 0$. Let $x_1, x_2, \ldots, x_n$ be a $\xi/2$ net, and let,
    $$0 < \alpha := \min_{1\leq j\leq m}\nu(B(x_j, \xi/2))$$
    this gives $B > \alpha > 0$


Therefore, all equilibrium measures are Gibbs states, which implies there exists a unique equilibrium measure called the Gibbs measure for all Holder continuous $\varphi \in C(X)$. 

\section{Transfer Operator}
We shall provide additional context to the content of the previous section by discussing transfer operators. Let's begin with some rudimentary motivations. Let,
$$m\circ T^{-1} \ll m$$
this gives, 
$$m(T^{-1}(A)) = \int_A \phi dm$$
where $\phi$ is the Radon-Nikodym derivative. If $T$ is a local homeomorphism, then, say for the evenly covered neighborhood $B(x, \xi)$ we have slices $U_1, U_2, \ldots, U_n$, then, 
$$m\circ \bigg(T\big|_{U_j}\bigg)^{-1} \ll m$$
so, 
$$m(T^{-1}(A)\cap U_j) = m((T|_{U_j})^{-1}(A)) = \int_A \phi_j dm$$
and by the uniqueness of the Radon-Nikodym derivative we have, 
$$\phi = \sum_{j= 1}^{n} \phi_j$$
Consider the map, 
$$\frac{d\mu}{dm} \rightarrow \frac{d(T_*\mu)}{dm}$$
where,
$$\frac{d(T_*\mu)}{dm} = \sum_{j= 1}^{n} \frac{d(\mu\circ(T|_{U_j})^{-1})}{dm} = \sum_{j=1}^{n}\bigg[\frac{d\mu}{dm}\circ(T|_{U_j})^{-1}\bigg]\phi_j$$
Define, 
$$L_m: L^1(m) \rightarrow L^1(m)$$
$$L_m(u)(x):= \sum_{\overline{x}\in T^{-1}(x)}u(\overline{x})\psi(\overline{})$$
where $\psi \equiv \phi_j\circ T$, and one can check that, 
$$L_m\bigg(\frac{d\mu}{dm}\bigg) = \frac{d(T_*\mu)}{dm}$$
Now, if $\exists$ $h\in L^1(m)$, $h\geq 0$ such that $\mu = h\mu$, then observe that, 
$$(\mu \text{ is }T\text{-invariant}) \iff (L_m(h) = h)$$
This is an operator theoretic way of constructing invariant measures. Our goal is to construct invariant Gibbs measures. Let $L_{\varphi}$ be the Ruelle operator, our job is two-fold - we've to find $m$ such that:-
\begin{enumerate}
    \item $m\circ T^{-1} \ll m$
    \item $\frac{d(m\circ T^{-1})}{dm} = \text{exp}(\varphi)$
\end{enumerate}
Then if $L_{\varphi}(h) = h$,  $hm$ would be invariant, and we could hope for it to also be a Gibbs state. If we see measures as functionals, we have the following,

$$L_{\varphi}^*(\mu)(f) = \mu(L_{\varphi}(f)) = \int_{T(B)}[f\text{exp}(\varphi)]\circ (T|_B)^{-1}d\mu$$
where $\text{supp}(f) \subseteq B$, and for $A\subseteq B$, one can find $\{f_n\}_n \in C(X)$ such that $f_n \rightarrow \chi_A$, which gives, 
$$L_{\varphi}^*(\mu)(A) = \int_{T(A)}\text{exp}(\varphi\circ (T|_A)^{-1})$$
for all $A$ such that $T|_A$ is injective. If $L_{\phi}^*(\mu) = \mu$, then we would have found the measure that satisfies $(1)$ and $(2)$ above. 

\subsection*{Theorem 5.1}
    There exists a measure $m_{\varphi} \in M(X)$ such that,
    $$L_{\phi}^*(\mu) = c\mu$$
    where $c = P(T, \varphi)$.

\textit{Proof.}
    Consider, 
    $$l: M(X) \rightarrow M(X)$$
    $$l(\mu):= \frac{L_{\varphi}^*(\mu)}{L_{\varphi}^*(\mu)(1)}$$
    Now, $M(X)$ is a compact convex set, which implies by the Schauder-Tychnoff theorem: $\exists$ $m$ such that,
    $$l(m) = m$$
    and one can also show that $c = L_{\varphi}^*(\mu)(1) = P(T, \varphi)$.

\subsection*{Theorem 5.2}
    The measure $m$ obtained in the previous theorem is a Gibbs measure for $\varphi$.

\textit{Proof.}
    It can be shown that,
    $$m(B(T^n(x), \xi)) = \int_{T_x^{-n}(B(T^n(x), \xi))}c^n\text{exp}(-S_n\varphi)dm$$
    and following an argument in the previous section we can also show,
    $$1 \geq m(B(T^n(x), \xi)) \geq \alpha$$
    as a result, 
    $$1 \geq \int_{T_x^{-n}(B(T^n(x), \xi))}c^n\text{exp}(-S_n\varphi)dm \geq \alpha$$
    using the pre-bounded distortion lemma, we get two things,
    $$\alpha \leq Cc^n \text{exp}(-S_n\varphi(x)))m(T_x^{-n}(B(T^n(x), \xi)))$$
    $$1 \geq C^{-1}c^n\text{exp}(-S_n\varphi(x))m(T_x^{-n}(B(T^n(x), \xi)))$$
    these put together give,
    $$\frac{\alpha}{C} \leq \frac{m(T_x^{-n}(B(T^n(x), \xi)))}{\text{exp}(S_n\varphi(x) - n\log(c))} \leq C$$

\subsection*{Theorem 5.3}
    Every invariant Gibbs measure is ergodic, and any two Gibbs measures for $\varphi$ are absolutely continuous.

An immediate consequence of this theorem is that there can at most be one invariant Gibbs measure. We already found $m_{\varphi}$, now it remains to find $h_{\varphi}$ such that $L_{\varphi}(h_{\varphi}) = h_{\varphi}$. In conclusion, 
$$h_{\varphi}m_{\varphi}$$
is the required unique Gibbs state for $\varphi$.

\section{Hausdorff Dimension}
A thorough treatment of Hausdorff measures is given in \cite{rogers1998hausdorff}. For the sake of completion, we give some basic definitions. 

\subsection*{Definition 6.1}
    Define, 
    $$H_{\delta}^d(S) := \inf\Bigg\{\sum_{i = 0}^{\infty}(\text{diam}(U_i))^d  \Bigg|  U_i \text{ covers }S, \text{diam}(U_i) < \delta\Bigg\}$$
    and set, 
    $$H^d(S):= \lim_{\delta \rightarrow 0}H_{\delta}^d(S)$$
    The outer measure defined by the function above is the $d$-dimensional Hausdorff measure.


Now note that, the function, 
$$\delta \rightarrow H_{\delta}^d(S)$$
is non-increasing. Furthermore, for $s<t$, we have for every $\delta > 0$, then, 
$$H_{\delta}^s(S) \geq \delta^{s-t}H_{\delta}^t(S)$$
\subsection*{Definition 6.2}
    There is a unique number denoted by $HD(S)$ such that,
    \begin{equation*}
        H^d(S) = \begin{cases}
      \infty & \text{if } 0\leq t < HD(S) \\
      0        & \text{if } HD(S) < t <\infty
    \end{cases}
    \end{equation*}
    that number is called the Hausdorff dimension of the set $S$.


These entities should be seen as fractional analogs of the Lebesgue measure. Now, using certain covering theorems we can prove the following crucial theorem.

\subsection*{Theorem 6.1}
    Assume that $\mu$ is a Borel probability measure on $\mathbb{R}^n$, and $S$ a bounded Borel subset of $\mathbb{R}^n$, then for $C>0$ the following things hold:-
    \begin{enumerate}
        \item for all but countable $x\in S$ if 
        $$\limsup_{r\rightarrow 0} \frac{\mu(B(x, r))}{r^d} \geq C$$
        then $H^d(A) \leq \frac{n}{C}\mu(A)$ for every Borel $A \subset S$.
        \item if for all $x\in S$
        $$\limsup_{r\rightarrow 0} \frac{\mu(B(x, r))}{r^d} \leq C < \infty$$
        then $\mu(A) \leq CH^d(A)$ again for all Borel subsets $A \subset S$.
    \end{enumerate}

\subsection*{Theorem 6.2 — Frostman's Lemma}
    Suppose $\mu$ and $S$ is as above, then the following hold:-
    \begin{enumerate}
        \item If $\mu(S)>0$ and there exists $\theta_1$ such that for every $x\in S$
        $$\liminf_{r\rightarrow 0} \frac{\log(\mu(B(x, r)))}{\log(r)}\geq \theta_1$$
        then $HD(S) \geq \theta_1$
        \item If there exists $\theta_2$ such that for all $x\in S$,
        $$\liminf_{r\rightarrow 0} \frac{\log(\mu(B(x, r)))}{\log(r)} \leq \theta_2$$
        then $HD(S) \leq \theta_2$.
    \end{enumerate}


One can read the proof of this theorem easily from the statement of the theorem preceding it. Having set the stage so far, let me also remark that one can get a description of the Hausdorff dimension of a measure via such limits (for more details on this refer \cite{falconer2004fractal}). We shall now introduce conformal expanders and state a technical theorem that combines all the characters introduced in the two sections above. 

\subsection*{Definition 6.3}
    $(J, V, T)$ is a conformal repeller if for $T:V\rightarrow \mathbb{C}$ (a holomorphic function), one has:-
    \begin{enumerate}
        \item $\exists$ $C>0$ and $\alpha > 1$ such that $|(T^n)'(z)| \geq C\alpha$, $\forall$ $z\in J$, and $n\geq 1$.
        \item $T^{-1}(V) \subset \subset V$, $J = \cap_{n\geq 1}T^{-n}(V)$.
        \item $\forall$ $U$, open, $U\cap J \neq \emptyset$, $\exists$ $n>0$ such that $J \subset T^n(U\cap J)$.
    \end{enumerate}

These objects satisfy some easy-to-observe topological properties summarized in the following theorem.
\subsection*{Theorem 6.3}
    Given $(J, V, T)$ a conformal repeller, the following statements hold,
    \begin{enumerate}
        \item $T(J) = J$, and $T^{-1}(J) = J$.
        \item $J$ is perfect.
        \item $\exists$ $\beta >0$, such that $\forall$ $x\neq y \in J$, $\exists$ $n$, such that, $|T^n(x) - T^n(y)|\geq \beta$ (i.e. $T$ is expanding on $J$).
        \item $J$ admits a Markov partition $\{J_i\}_{1\leq i\leq k}$.
    \end{enumerate}


\subsection*{Theorem 6.4 — Distortion Lemma}
    Let $m$ be a Gibbs state on $X$, and $\varphi: X\rightarrow \mathbb{R}$ be Holder continuous. Assume $P(\varphi) =0$. Then there is a constant $E\geq 1$ such that for all $r$ small enough and all $x\in X$ there exists $n = n(x, r)$ such that,
    $$\frac{\log(E) + S_n\varphi(x)}{-\log(E) - \log(|(T^n)'(x)|)} \leq \frac{\log(m(B(x, r)))}{\log(r)} \leq \frac{-\log(E) + S_n\varphi(x)}{\log(E) - \log(|(T^n)'(x)|)}$$

With this result, one gets the volume lemma easily.
\subsection*{Theorem 6.5 — Volume Lemma}
    Let $m$ be a Gibbs state for a topologically mixing conformal expanding repelled on $X$. Let $\varphi$ be a Holder continuous real function. Then for almost every $x\in X$, the limit,

    $$\lim_{r\rightarrow 0}\frac{\log(m(B(x, r)))}{\log(r)}$$
    exists and is equal to $\frac{h_{\mu}(T)}{\chi_{\mu}(T)}$ (where $\chi_{\mu}(T)$ is the Lyapunov exponent. 

\textit{Proof.}
    Without any loss of generality assume that $P(\varphi) = 0$. We can achieve this by subtracting $P(\varphi)$ from $\varphi$. It can be shown that the Gibbs measure class remains the same up to constant perturbation of the Holder potential $\varphi$. Now by Birkhoff's Ergodic Theorem, for almost every $x\in X$, we have, 
    $$\lim_{n\rightarrow \infty }\frac{1}{n}S_n\varphi(x) = \int \varphi d\mu$$
    $$\lim_{n\rightarrow \infty} \frac{1}{n}\log|(T^n)'(x)| = \chi_{\mu}(T)$$
    combining these equalities with the distortion lemma above, and noticing that $n \rightarrow \infty$ as $r\rightarrow 0$, and also using the Variational Principle, we get,

    $$\lim_{r\rightarrow 0}\frac{\log(\mu(B(x, r)))}{\log(r)} = \frac{h_{\mu}(T)}{\chi_{\mu}(T)}$$


This finally gives us the cute formulation which generalizes to any $f$-invariant ergodic measure $\mu$, 

$$HD(\mu) = \frac{h_{\mu}(T)}{\chi_{\mu}(T)}$$


In \cite{zinsmeister2000thermodynamic} one would find a way to get a sub-shift system out of a given conformal repeller with the help of its Markov partition. We defer from discussing that here, for it's a bit technical. But the essential reason we began this section is to state the following magical result. 

The function $\phi = -\log{|T|'}$ is Holder continuous. We now know from Theorem $4.4$ that $\pi(t) = P(t\phi)$ is real analytic, and that $\pi(0)$ is the topological entropy of the so obtained sub-shift system, which has to be greater than 0. One can further show that $\pi$ is strictly decreasing with,
$$\lim_{t\rightarrow \infty}\pi(t) = -\infty$$

which implies that there exists a $t>0$ such that $\pi(t) = 0$.
\subsection*{Theorem 6.6 — Bowen} Let $t = \text{Hausdorff dimension of }J$, then $\pi(t) = 0$.
